# Domain language

| Term | Meaning |
| --- | --- |
| Environment Program | Optional authoring intent attached to one canonical World Engine environment. It describes design; it owns no world or scene state. |
| Intent | Short statement of environment function, desired player experience, and tone. |
| Visual goal | Inspectable claim about composition in the rendered environment, not a rendering command. |
| Activity | Normal use of a place. It does not imply an actor is currently present. |
| Group | Named authoring vignette referencing existing scene anchors and activities. No coordinates, collision, or lifecycle. |
| Contribution | Optional explanation of what an existing element adds to the room, including purely aesthetic value. |
| Relationship | Authored design claim between existing anchors, limited to spatial facts the scene can check. |
| Ambient residue | Ordinary, baseline signs of use that assert no specific story event. |
| Narrative residue | Visible trace of a specific event, allowed only when canonical narrative state supports it. |
| Room Critic | Evidence-led review at room, group, and object levels; it does not mutate canonical world state. |
