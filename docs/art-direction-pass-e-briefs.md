# Art Direction Pass E — exteriors, Roadhouse, Ghostwood (brief pack)

Status: briefs ready, nothing implemented. Owner of the bar: Fable. Builders: cheap labor, one brief per night, fresh-context critic per round (Gauntlet Loop, vault `Concepts/Gauntlet Loop Prompting.md`).

The references are 1448x1086. The game is 160x144. Builders reproduce the **grammar**, never the pixels: a pine is 2 tiles wide, fog is a 3-tone dither band, a lamp pool is a stepped ellipse of two tones. Anything that needs more than 4 tones per object does not fit and must be simplified, not blurred.

## House rules (every brief)

- Production renderer only: `index.html` + `js/retro.js`. Screenshots with `test/shot.sh <map> <x> <y> <dir> <out.png> --retro`.
- Palette: the bar image defines hue and value ranges. The scene must stay inside the global retro palette limit (`GAME.Retro2D.limitBackgroundPalettes`) unless the scene installs a native override the way `js/double-r-exterior-scene.js` does.
- Native scene pattern to follow: `js/<scene>-art.js` (drawing) + `js/<scene>-scene.js` (install hooks: `drawTile`, `drawStructures`, `drawForegroundStructures`) + `js/<scene>-production.js` (register). See `js/hospital-*.js`, `js/double-r-exterior-*.js`.
- Ambient motion registers in `js/ambient-life-scenes.js` using the existing archetypes (`STEAM_SMALL`, `LIGHT_WARM_VARIATION`, `LIGHT_NEON`, `MACHINE_IDLE_ACTIVITY`, `CLOCK_TICK`, `GLASS_SUBTLE_REFLECTION`). New archetypes go in `js/ambient-life.js` only if none fits; name them in the report.
- Map rows, doors, NPC positions, walkability: unchanged unless the brief says so. Cast Presence owns every named body (`narrative/cast/windows.json`), builders never place a named character.
- Gates before any screenshot: `node test/smoke.js` (415), `node test/walkthrough.js` (85), `node test/cast-continuity-validate.js`, `node test/retro-production.js`, `node test/mobile-production.js`.
- Critic packet per round: bar image, current shot, one-line goal, house rules. No builder notes. Critic returns: winner (bar/ours), score 0-10, one biggest gap.
- Floor: 7/10 from a fresh critic on every unit before the scene is called done. Average does not hide a weak unit.
- Evidence: `artifacts/art-pass-e/<scene>/round-<n>.png` + `progress.md` (bar, baseline, current, score, gap, owner).
