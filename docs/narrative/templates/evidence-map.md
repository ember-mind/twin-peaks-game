# Evidence map — `artifacts/<milestone>/evidence-map.md`

PURPOSE: audit every atom, value and flag of an investigation: who writes it, whether the player sees it, what it combines with, what it produces; then the verdict.
WHEN REQUIRED: investigation content (observations, testimony, comparisons, propositions). Non-investigative scenes: skip.

FIELDS:
1. As built: `atom/value | source (writer node) | mandatory? | visible (a page states it) | independent (meaningful alone) | combines with | produces | verdict KEEP / REWRITE / MERGE / CUT / DEFER`.
2. Player vs Cooper vs state: `deduction | player has seen | Cooper may infer | state knows | gap`.
3. Proposed atoms (content-level): `atom | target (map) | kind object/observation/testimony | page that states it | supports | combines`.
4. Cross-mission consumption: `later point | reads | effect`.

PASS: every atom a system depends on is mandatory and has a visible page; every deduction in §2 has "player has seen" ≥ its premises; object ≠ testimony kept (a claim never appears as an observation atom); no atom added without a reader.
FAIL: an atom "visible: no" that a comparison requires; a proposition formulated from testimony alone; ADD rows that need a runtime primitive (that is an engine-pressure D, argued in the act design).

WHAT NOT TO PUT HERE: dialogue, objective truth, theory wording.
