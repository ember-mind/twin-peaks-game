# Setup–Payoff Ledger — `artifacts/<milestone>/setup-payoff-ledger.md`

PURPOSE: every promise the text makes is either paid, deliberately left open, or a defect; and every important payoff survives ablation.
WHEN REQUIRED: every act; any scene that opens or closes a setup.

FIELDS: `# | SETUP (page id, quoted) | PAYOFF (page id or "none") | STATUS: PAID / INTENTIONAL-UNRESOLVED / UNPAID | WHAT THE PLAYER MUST HAVE EXPERIENCED (route condition) | ABLATION RESULT (delete setup / neutralise return → same function?) | note`
Then "Frozen resolution": each UNPAID row → repair or reclassification with the reason.

PASS: no UNPAID row on a mandatory setup at freeze; every INTENTIONAL-UNRESOLVED names where it is meant to pay (act or "finale") or says "never, by design"; ablation run on every payoff the act claims as meaningful (stances, deaths, custody, promises).
FAIL: a PAID whose payoff is a verbal callback only (changed-affordance check fails); a state written for a payoff that no later node reads; "unresolved" used to hide a forgotten thread.

WHAT NOT TO PUT HERE: facts (fact ledger), theme statements, the payoff's prose.
