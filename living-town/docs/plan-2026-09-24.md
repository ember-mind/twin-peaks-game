  (`tools/gen-town-map.js` -> `js/lt-town.gen.js`); real walking, 3 cells per
  town minute; "together" outside = within 10 cells and in sight; people with
  an appointment look for each other in that zone.
- page draws outside with the engine (`js/lt-kit-town.js`); rooms as before.
- "Whole town" view in the Follow row (all outside, indoor names over doors).
- save migrations chain d7dfa67e -> 98626395 -> c0e11a4d -> 20f71e57, each
  written against a real save in `test/fixtures/`.

**Minds and readability**:
- thought bubbles (`js/lt-bubbles.js`): thinking "…", forks "a / b ?" then
  the chosen one, Jev's odds when Jev decided; activity signs otherwise.
- hourly intentions (`js/lt-intentions.js`, action `plan_hour`): work /
  company / stay in / go out / food, an ordinary decision; the offline
  policy leans towards what fits.
- server `--jev` (`server/town-server.js`): hybrid asks Jev on close calls,
  forks and hour plans; `--jev-budget` per real day (default 100); every
  frame says whether the mind is offline. Verified with 3 real calls.
- pace: 1x = a town minute a second; Auto (default) 1 s to 20 ms a minute;
  a decision on screen slows the town to 3 s a minute.

## How to run

- page, offline: serve the repo (`python3 -m http.server 8792`) and open
  `http://127.0.0.1:8792/living-town/?world=new`.
- live town: `node living-town/server/town-server.js [--jev --jev-budget=100] --port=8793`.
- checks: `node living-town/test/run-all.js`; release gates
  `node tools/run-release-tests.js --out=<dir>`; browser tests
  `living-town/test/page-{story,live,persistence}-browser.js` (one Chrome at
  a time: `until mkdir /tmp/lt-chrome.lock; do sleep 5; done; …; rmdir /tmp/lt-chrome.lock`).
- changing `town.json` -> `node living-town/tools/gen-town-map.js`, then a
  save migration for the new fingerprint (`LT.World.fingerprint()`).
- boredom baselines after behaviour changes:
  `node living-town/tools/measure-boredom.js --write-baseline` and `--cast=town`.
